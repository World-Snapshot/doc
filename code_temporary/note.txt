核心概念：

1. 像素与波函数结合
- 每个像素具有3D坐标(x,y,relative_depth)
- 波函数ψ(x,y,z,t) = A * exp(i(kx*x + ky*y + kz*z - ω*t))
- 波函数值映射到像素160维状态向量
- 波函数振幅和相位决定像素量子态

2. 实虚像素结构
- 3x3网格，中心为实像素
- 周围8个为虚像素
- 通过波函数描述实虚像素间关系

3. WSG (World State Grid)
- 单视角世界状态网格
- 包含波函数状态
- 包含相对深度信息
- 每个像素160维状态向量

4. WSF (World Snapshot Field)
- 多视角WSG合集
- 统一3D场表示
- 视角合并权重计算
- 不确定性度量

5. 波函数关键特性
- 复数值表示振幅和相位
- 描述量子态叠加
- 支持平滑过渡
- 可进行干涉计算

6. 坐标系统
- 图像平面坐标(x,y)
- 相对深度z∈[0,1]
- 相机位置和朝向
- 世界坐标变换

7. 视角转换
- 相机参数定义
- 投影矩阵计算
- 坐标系转换
- 视角权重计算

8. 状态合并
- 多视角信息融合
- 波函数干涉计算
- 几何一致性评估
- 不确定性分析

9. 生成流程
- text -> WSG单视角生成
- 多视角WSG生成
- WSG -> WSF合并
- 后处理优化

10. 关键算法
- 波函数演化
- 视角合并
- 空洞填充
- 不确定性计算
